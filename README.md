# Squaron
If snake had two players.



## how it works
It shrinks a normal html file into the URI only page using a build script.


## building
1. Clone the repository: 
```
git clone https://www.github.com/AGVtrop/squaron.git
cd squaron
```
2. Build it:
```
npm install
node build.mjs
```
3. The output code will be in dist/

## Running:
Paste the dist/uri.txt into your browser's URL bar, or copy it straight from here :D
[URI link](dist/uri.txt)
